# Security Policy

Please do not publish exploitable security details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository owner privately through GitHub. Include the affected commit/version, impact, and a minimal reproduction. Never include real user secrets or private datasets.

The current implementation is an early development foundation, not a production security certification. Read [the detailed security policy](docs/SECURITY.md) for implemented controls, known gaps, and deployment warnings.

Security issues are prioritized over feature requests. Please allow time for a fix and coordinated disclosure before public discussion.
